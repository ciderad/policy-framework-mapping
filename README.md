# Policy-Framework Mapping & Gap Analysis

A structured compliance mapping project demonstrating how organizational policies align with recognized security frameworks (NIST CSF 2.0), identifying coverage gaps, and validating control maturity.

## Objective
To bridge the gap between high-level regulatory frameworks and internal documentation, ensuring that every operational security control maps cleanly to compliance requirements.

## Frameworks & Tools Used
* **NIST Cybersecurity Framework (CSF) 2.0**
* **Internal Governance Policy Design**
* **Compliance Cross-Walking & Gap Analysis**

## Repository Structure
* `policies/`: Contains sample company governance policies (Access Control, Incident Response).
* `mapping-matrix.csv`: The master cross-reference table mapping internal policy clauses to NIST CSF 2.0 subcategories.

## Key Findings from the Mapping
1. **Access Control Alignment:** Strong coverage on identity management and MFA requirements, fully satisfying NIST PR.AC controls.
2. **Incident Response Gaps:** Identified that while incident reporting is robust, automated evidence retention for post-incident reviews requires process refinement.
